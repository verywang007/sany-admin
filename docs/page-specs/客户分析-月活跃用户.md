# 客户分析-月活跃用户 页面规格

> 来源：`客户分析-月活跃用户.html`，是 HZERO 线上系统 c7n-ui 渲染后的 DOM 快照。页面上没有页面级交互脚本，`local-nav-interact` 和 `local-layout-fix` 已忽略。
> 补充来源：同目录线上打包源码 `assets/packages/gcp-front-admin/static/js/72.244ab3f2.chunk.js`（module 1414，即本页组件和 DataSet），样式 `assets/packages/gcp-front-admin/static/css/72.873f508c.chunk.css`（`.customer_headerTips__2rYFL`）。
> 复杂度：**低**。只读的报表列表，由查询栏、「活跃率」指标提示条、导出按钮、表格和分页组成。没有操作列，也没有弹窗。

## 1. 页面标题、面包屑、页签

- 页面标题（`PageHeaderWrapper title`）：**月活跃用户**。`.page-head-operator` 为空。
- 面包屑：没有。菜单路径为一级菜单「**客户分析**」（侧栏中处于激活态，class 为 `hzero-main-menu-item-hzero-customer_analysis`）下的「月活跃用户」。
- HZERO 多页签栏（框架层）：工作台（home 图标，不可关闭）/ **月活跃用户（激活）** / 用户留存率 / 账户管理 / 异常申诉 / 租户审核 / 设备管理员配置 / 组织管理 / 直接创建租户 / 客户认证使用 / 客户分析。
- 页面内没有 Tabs。
- 框架顶栏和侧栏与其他 HZERO 页面相同：MySANY管理平台、新加坡站点、三一集团、简体中文、产品顾问-刘伏旺；侧栏一级菜单依次为活动管理模块、活动管理、广告管理、审核检查、**客户分析**、客户管理、数据管理、设备管理、反馈管理、圈子管理、通用配置、积分商城管理、保养台账管理、运营活动管理、系统设置、开发管理、消息管理。

## 2. 查询区

使用 c7n-pro Table 的 professional 查询栏，一行 3 个字段，标签右对齐并带冒号。colgroup 宽度依次为：标签 0.8rem / 字段 / 标签 0.8rem / 字段 / 标签 1.4rem / 字段。第 3 个字段设置了 `labelWidth: "140"`。

| # | 标签 | name | 控件 | placeholder | 选项 | 默认值 | 其他 |
|---|---|---|---|---|---|---|---|
| 1 | 查询月份 | `yearMonth` | **月份选择器**（`type: month`），右侧有日历图标，可清除 | 请选择月份 | — | **当前月** `dayjs/moment().format('YYYY-MM')`，快照中为 `2026-09` | `max: 当前时间`，不能选未来月份 |
| 2 | 查询国家 | `countryCodes` | **LOV 多选**（`type: object`，`lovCode: CUSTOMER.COUNTRY`，`multiple: true`），右侧是搜索图标，可清除，选中后以多选 tag 展示 | 请选择国家 | 来自 LOV `CUSTOMER.COUNTRY`：显示字段 `cityname`，值字段 `citycode` | 空 | 提交时转为 `citycode` 用逗号拼接的字符串 |
| 3 | 是否印尼标签用户 | `label` | **下拉单选**（不可输入），可清除 | 快照中无 placeholder | **是**（value `"1"`）/ **否**（value `"0"`） | 空 | |

- 查询栏按钮：「重置」（默认按钮）、「查询」（主按钮）。
- 没有“更多查询”和展开/收起。
- 进入页面时自动查询（`autoQuery: true`）。

## 3. 工具栏

工具栏（`c7n-pro-table-professional-toolbar`）整行是一个提示条（快照修补后的类名为 `.local-table-tips-bar`：`display:flex; align-items:center; justify-content:space-between; width:100%`），工具栏上下 padding 各 0.16rem。

- **左侧：指标提示**（`.customer_headerTips__2rYFL`：`display:flex; align-items:center; gap:30px; font-size:14px; width:70%`；直接子 div 的颜色为 `#333`）
  - 第 1 行（`font-size: 24px`，行高 1.5）：**`活跃率 = {activeRate}%`**，快照中为「**活跃率 = 8.99%**」。初始值为 `--`，请求失败或无值时显示 `--`，即「活跃率 = --%」。
  - 第 2 行（14px，与第 1 行间距 0.04rem）：**月活跃率=本月活跃用户数/本月用户总数**
- **右侧：导出按钮**。这是 HZERO ExcelExport 权限按钮（antd `ant-btn hzero-permission-btn`），图标为 `anticon-export`，文案「**导出**」。样式是**文字按钮**：`color:#29bece; padding:0 0.12rem; border:none; margin:0; background:transparent`。
- 没有新增或其他按钮。

## 7. 交互逻辑

- **列表接口**：`GET /customer/v1/{orgId}/infos/active-user`。参数处理（transport.read）如下：
  1. 深拷贝查询数据。
  2. `yearMonth` 格式化为 `YYYY-MM`。
  3. `countryCodes` 由对象数组转为 `citycode` 的逗号拼接字符串。
  4. 用同一份参数**同时**调用活跃率接口（见下）。
  5. 最终请求参数为 `{...分页参数, ...处理后的查询参数}`。
- **活跃率接口**：`GET /customer/v1/{orgId}/infos/active-user/active-rate?{同上参数}`，响应中的 `data` 写入 `activeRate`，显示为「活跃率 = {data}%」。每次列表查询（包括首次自动查询、点查询、重置后的查询、翻页）都会重新请求活跃率。重写时**只需在查询条件变化时请求**，翻页时不必重复请求。
- **导出**：ExcelExport 组件，`method: get`，`defaultSelectAll: true`，文件名为 `月活跃用户_{YYYYMMDD}`，请求地址 `/customer/v1/{orgId}/infos/active-user`（与列表接口相同，由 HZERO 导出框架加 export 参数），`queryParams` 使用 `getQueryParameter()`：yearMonth 格式化，countryCodes 拼接，并去掉值为 undefined/null/'' 的键。
  - 源码中另有一个 `exportExcel()` 方法，调用的是 `/aftersale/v1/{orgId}/report-problem/export/param`，文件名为“设备数据异常反馈管理”。这是复制残留，**没有被调用**。
- 重置：清空查询国家和是否印尼标签用户，查询月份恢复默认（c7n 重置会恢复 defaultValue，即当前月）。
- 查询月份不能晚于当前时间（`max`）。

## 8. 特殊视觉

- **指标大字**：「活跃率 = 8.99%」，24px，颜色 `#333`；下方公式说明为 14px。提示区占工具栏宽度的 70%，导出按钮在最右侧。
- 导出按钮为青色文字按钮，颜色 `#29bece`，无边框，背景透明。
- 没有图表，也没有统计卡片（只有上面这个指标）。
- 表格行高自适应（auto），长文本会换行，不省略。
- 空状态：c7n 默认文案「暂无数据」（本页快照中有数据，空状态参见用户留存率页）。
- 水印：14 个 `div.mask_mark`，文字为「产品顾问-刘伏旺」。样式为 `rotate(-15deg)`、`opacity 0.2`、12px、字体微软雅黑、颜色 `rgb(170,170,170)`、尺寸 210×60、`pointer-events:none`、`z-index:1000`。分两列排列（left 20px / 391px），top 依次为 56、174、292、410、528、646、764。

## 9. 其他细节

- 与「用户留存率」页结构几乎一样：查询字段、表格列、导出样式完全相同，只是接口、指标文案和公式不同。重写时建议抽成同一个组件，通过配置区分。
- 指标数值直接拼接 `%`，前端不做格式化。接口返回的是百分数值，例如 `8.99`。
- 是/否值集是本地定义的（`{text:'是',value:'1'},{text:'否',value:'0'}`，单选），查询字段和表格列共用。
- 方案文档 `客户管理-账户注销-方案.md` §9 提到：已注销用户的历史活跃应**计入**月活跃用户（时间序列报表保留历史事实）。这一点影响后端口径，前端不受影响。
- 尺寸单位是 rem（HZERO 中 1rem = 100px）。
