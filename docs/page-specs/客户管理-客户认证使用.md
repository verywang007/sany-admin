- 接口：`GET /customer/v1/{organizationId}/customer-info-crm-assess/getManagerPage`

- DataSet：`pageSize: 20`，`autoQuery: true`，`primaryKey: id`
- 另外定义了 `transport.update`：`POST /customer/v1/{org}/city-platform-settings`，body 为 data[0]（页面里没有用到）

- `assessStatus === "0"`（已剔除）→ 按钮 **重新考核**（c7n Button，flat，默认色）

## 6. 弹窗：导入（导入客户信息 / 导入考核国家）

- 组件：c7n 普通 `Modal`（受控，`visible = state.showBindModal`）
- 标题：类型 2 → **导入客户信息**；类型 1 → **导入考核国家信息**（注意：按钮叫“导入考核国家”，弹窗标题多了“信息”两个字）
- 宽度 600，`closable: false`（没有右上角 ×），`footer: null`（底部按钮在内容里自己画）
- 打开时重置：`editItem={id:""}`，`files` 保持（关闭时清空）
- 内容（外层包 Form `ref=editFrom`）：
  1. 行“**下载导入模板:**”（标签区 `position:absolute; left:0.24rem; width:100px; text-align:right; padding-right:0.1rem`，内容区 `padding-left:100px`）
     - 链接：`cursor:pointer; color: rgb(41,190,206)`（#29bece），前面是 18px 宽的下载图标（SVG，填充色 `#29bece`，`margin-right:8px`）
     - 文案：类型 1 → `考核国家信息模板下载`；类型 2 → `客户信息模板下载`
     - 点击：`GET {HZERO_FILE}/v1/{org}/files/download-by-key?fileKey=<模板 fileKey>`，blob；成功后下载为 `考核国家信息模板.xlsx` / `客户信息模板.xlsx`（MIME `application/vnd.openxmlformats-officedocument.spreadsheetml.sheet;charset=utf-8`）；`failed` 或异常 → notification.error `消息提示 / 下载失败`
     - 模板 fileKey 来源：页面加载时请求值集 `GET /hpfm/v1/{org}/lovs/data?lovCode=CRM.USERLIST.TEMPLATE`，`meaning === "考核国家信息模板"` 的项的 `value` 作为模板 1，`meaning === "客户信息模板"` 的项作为模板 2
  2. 行“**\* 上传附件:**”（星号为红色 `color:red`，表示必填）
     - `Upload.Dragger`（拖拽上传区）：
       - action：`{HZERO_FILE}/v1/{org}/files/multipart`；headers `Authorization: bearer <token>`、`Access-Control-Allow-Origin: *`；data `{ tenantId, bucketName: "s3", directory: "/customer/operationManual" }`；`multiple: false`
       - 内部（`padding: 20px 0`）：
         - 上传图标（40px 宽的 PNG，`c7n-upload-drag-icon`）
         - 文案 `将文件拖到此处，或` + 青色 `#29BECE` 的 `点击上传`（`c7n-upload-text`）
         - 提示 `只能上传xls、xlsx格式文件，文件不能超过50M`（`c7n-upload-hint`）
       - `beforeUpload`（**总是返回 false**，即不真正上传，只把文件存进 state.files）：
         - 扩展名不是 `xls`/`xlsx` → notification.error `消息提示 / 只能上传xls、xlsx格式文件`
         - 大小 ≥ 51MB（判断式是 `size/1024/1024 < 51`）→ notification.error `消息提示 / 文件不能超过50M`
         - 通过 → `files = [file]`（只保留一个）
       - onRemove：按 name 移除
       - fileList 显示 state.files
  3. 底部右对齐按钮：
     - **取 消**（文字中间有空格，default）→ 关闭弹窗，清空 files 和 editItem
     - **确 认**（primary）；提交中显示 loading 状态的“确 认”（不可点）
- 确认逻辑（`bindConfirm`）：
  1. 提交中（saveLoading）时直接返回
  2. Form 校验 `checkValidity()` 不通过则返回
  3. 没有文件 → notification.error `消息提示 / 请上传附件`
  4. `saveLoading=true`；用 FormData（`file` = files[0]）`POST /customer/v1/{org}` + 路径：类型 1 → `/customer-info-crm-assess/batch-import-country`，类型 2 → `/customer-info-crm-assess/batch-import-customer`
  5. 返回结果：
     - `failed` → notification.error `消息提示 / {后端 message || "文件异常，导入失败"}`（弹窗不关）
     - 否则先按当前页重查，再根据计数：
       - `failCount === totalCount` → notification.error
       - `failCount > 0` → notification.warn
       - 否则 → notification.success
       - 三种的 description 都是：`导入总条数${totalCount},成功导入${successCount},失败${failCount}`（标题都是“消息提示”）
       - 然后关闭弹窗
     - 请求异常 → notification.error `消息提示 / 文件异常，导入失败`

## 7. 交互逻辑汇总

1. 进入页面：自动查询列表（pageSize 20）；加载模板值集 `CRM.USERLIST.TEMPLATE`；国家列的选项从 `/citys/page` 加载。
2. 状态流转（考核状态 assessStatus）：考核中("1") ⇄ 已剔除("0")
   - 单行：考核中 → “剔除考核”（红）→ 变成已剔除；已剔除 → “重新考核” → 变成考核中
   - 批量：“批量剔除考核”统一设为 0，“批量重新考核”统一设为 1，必须先勾选
3. 所有成功/失败提示都用 notification（右上角通知框），标题固定为“消息提示”。
4. 导入弹窗规则见第 6 节；导入结果按成功/部分失败/全部失败分别用 success、warn、error 提示。
5. 刷新：调用后端刷新接口后重查当前页。
6. 以上操作都没有确认对话框。
