# 客户管理-设备管理员配置 页面规格

> 来源：`客户管理-设备管理员配置.html`（HZERO 线上系统 c7n-ui 渲染后 DOM 快照，无页面级交互脚本，仅有被忽略的 `local-nav-interact` 与 `local-layout-fix`）。
> 页面复杂度：低到中（标准 CRUD 列表页，另有新增/编辑弹窗，其中区号和手机号互为条件必填，还有带文件校验的导入弹窗）。快照本身没有弹窗，弹窗和逻辑来自同目录 `assets/packages/gcp-front-admin/static/js/188.0d9e5b6e.chunk.js`、`22.7e2d17fc.chunk.js` 中的线上前端打包源码。

## 1. 页面标题、面包屑、页签

- 页面标题（`.page-head-title`）：**设备管理员配置**；`.page-head-operator` 为空（标题栏右侧无按钮）。
- 面包屑：无独立面包屑组件。所在菜单路径为一级菜单「客户管理」（侧栏中该项为激活态 `hzero-main-menu-item-tab-active hzero-main-menu-item-hzero-customers`）→ 「设备管理员配置」。
- 顶部多页签（HZERO 菜单页签，卡片式可关闭，属于框架而非页面本身）顺序：工作台(带 home 图标，不可关闭) / 月活跃用户 / 用户留存率 / 账户管理 / 异常申诉 / 租户审核 / **设备管理员配置（当前激活）** / 组织管理 / 直接创建租户 / 客户认证使用 / 客户分析。
- 页面内部没有 Tabs。
- 框架顶栏：系统名「MySANY管理平台」；站点切换「新加坡站点」；租户下拉「三一集团」；语言「简体中文」；消息铃铛；用户「产品顾问-刘伏旺」。
- 侧栏一级菜单（顺序）：活动管理模块、活动管理、广告管理、审核检查、客户分析、客户管理（激活）、数据管理、设备管理、反馈管理、圈子管理、通用配置、积分商城管理、保养台账管理、运营活动管理、系统设置、开发管理、消息管理；顶部有「菜单搜索」输入框。

## 2. 查询区

c7n-pro Table `professional` 查询栏（`c7n-pro-table-professional-query-bar`），一行三列横向表单，标签右对齐带冒号。
colgroup 宽度：标签列 0.8rem / 字段 / 标签 0.8rem / 字段 / 标签 1.3rem / 字段。

| # | 标签 | 字段名(name) | 控件 | placeholder | 默认值 |
|---|------|------|------|------|------|
| 1 | 客户名称 | `crmCustomerName` | 文本输入框 | 请输入 | 空 |
| 2 | 客户编码 | `crmCustomerNo` | 文本输入框 | 请输入 | 空 |
| 3 | 管理员MySany账号 | `adminMysanyNo` | 文本输入框 | 请输入 | 空 |

- 查询栏右侧按钮：「重置」（默认按钮，`professional-reset-btn`）、「查询」（主按钮）。
- 无“更多查询”/展开收起按钮（仅 3 个字段，未超出一行）。

## 3. 工具栏按钮（表格上方左侧，按顺序）

1. **新增** —— 主按钮（primary），图标 `icon-add_box-o`。
2. **导入** —— 默认按钮，图标 `icon-backup_line`（云上传）。
3. **导出** —— 默认按钮（antd `ant-btn hzero-permission-btn`，权限按钮），图标 `anticon-export`；内联样式：文字色 `rgb(51,51,51)`，背景白色，左右 margin 0.1rem。

## 4. 表格

c7n-pro Table，带边框（bordered），行高 0.36rem（≈36px），列可拖拽调整宽度（`column-resizable`），表格总宽 6.8rem，内容区横向可滚动（`content-overflow`），左右固定列有 sticky 阴影。

| # | 列标题 | 字段(data-index) | 宽度 | 对齐 | 固定 | 渲染 |
|---|--------|------|------|------|------|------|
| 0 | （无标题）行号（`rowNumber: true`） | `__row-number-column__` | 0.5rem（min 0.5rem） | 居中 | 左固定 | 序号 1~20 |
| 1 | 客户名称 | `crmCustomerName` | 1rem | 左 | 否 | 纯文本 |
| 2 | 客户编码 | `crmCustomerNo` | 1rem | 左 | 否 | 纯文本 |
| 3 | 管理员名称 | `adminName` | 1rem | 左 | 否 | 纯文本 |
| 4 | 管理员手机号 | `adminPhone` | 1rem | 左 | 否 | 纯文本，格式 `(区号)号码`，可为空 |
| 5 | 管理员MySany账号 | `adminMysanyNo` | 自适应（仅 min 0.5rem） | 左 | 否 | 纯文本 |
| 6 | 操作 | `id` | 1.3rem | 居中 | 右固定 | 两个文字按钮 |

- 单元格为固定行高、单行显示（`row-height-fixed`），超长文本会被截断（c7n 默认 ellipsis）。
- 第一行处于当前行高亮状态（`c7n-pro-table-row-current`）。
- 操作列：
  - **编辑** —— 文字按钮（flat，primary 蓝色），每行都显示。
  - **删除** —— 文字按钮（flat，red 红色），每行都显示。
  - 快照中没有显示条件，所有行都有这两个操作。

## 6. 弹窗 / 抽屉 / 详情

快照中的 `c7n-pro-modal-container` 是空的，没有保存打开状态的弹窗。以下弹窗定义来自同目录的线上前端打包源码 `assets/packages/gcp-front-admin/static/js/188.0d9e5b6e.chunk.js`（页面组件，module 1358）和 `22.7e2d17fc.chunk.js`（DataSet 定义，module 483）。文案中凡是通过 i18n 函数 `intl(key, 默认值)` 取的，都给出 key 和默认中文；只有 key、没有默认值的，标出推测文案。

### 6.1 新增 / 编辑弹窗（同一个弹窗）

- 组件：c7n `Modal`，`width: 600`，`closable: false`（没有右上角 ×），`footer: null`（按钮放在内容区底部，右对齐）。
- 标题：`addForm.id` 有值时为 **编辑**（key `edit`），否则为 **新增**（key `hzero.common.btn.add`）。
- 打开方式：「新增」时表单重置为空；「编辑」时 `addForm = {...record.data}`（回填当前行所有字段，包括 `id` 和 `internationalTelCode`）。
- 表单（c7n `Form`，字段纵向排列）：

| # | 标签 | name | 控件 | 必填 | maxLength | placeholder | 其他 |
|---|---|---|---|---|---|---|---|
| 1 | 客户名称（key `customer-name`） | crmCustomerName | TextField 文本输入 | 是 | 100 | `intl('please-enter')` + 客户名称，即「请输入客户名称」 | |
| 2 | 客户编码（`customer-code`） | crmCustomerNo | TextField | 是 | 100 | 请输入客户编码 | |
| 3 | 管理员名称（`admin-name`） | adminName | TextField | 是 | 100 | 请输入管理员名称 | |
| 4 | 管理员手机号（`admin-phone`）：标签是自定义绝对定位的 div（`left:-94px; line-height:28px`，文字后带「:」） | 由两个控件组成一行（Row） | 见下 | 条件必填 | | | |
| 4a | （区号） | internationalTelCode | Select 下拉，`searchable`，自定义 searchMatcher（按选项 `meaning` 不区分大小写包含匹配） | **当 adminPhone 有值时必填** | | 请选择（key `please-select`） | Col span=8。选项来自城市接口 `GET /customer/v1/{orgId}/citys/page`（pageSize 999，dataKey `data.content`）：value = `internationalCallPrefix`，文案 = `${cityName}(${internationalCallPrefix})`，例如「印度尼西亚(62)」 |
| 4b | （号码） | adminPhone | NumberField 数字输入，`numberGrouping: false`（不加千分位），宽 100%，class `index_numberField__1LqWG` | **当 internationalTelCode 有值时必填** | 100 | 请输入管理员手机号 | Col span=15，offset=1 |
| 5 | 管理员MySany账号（`admin-account`） | adminMysanyNo | TextField，`labelWidth: 130` | 是 | 100 | 请输入管理员MySany账号 | |

- 联动规则（`formItemChange`）：区号被清空时，`internationalTelCode` 设为 `null`；其他字段取 `e.target.value`，或直接取值，空值存为 `''`。区号和号码互为条件必填：要么都填，要么都不填。
- 底部按钮（右对齐）：**取消**（key `cancel`，default）、**确定**（key `confirm`，primary；保存期间显示为 loading 状态的“确定”按钮）。
- 提交（`handleAddConfirm`）：
  1. 若 saveLoading 为真则直接返回，防止重复提交。
  2. 执行 `form.checkValidity()`，不通过则停止（c7n 在字段上显示必填提示）。
  3. `POST /customer/v1/{orgId}/customer-device-managers`，body 为 `{...addForm, id: addForm.id || undefined}`（新增和编辑共用同一接口，按是否有 id 区分）。
  4. 成功：刷新当前页（`ds.query(ds.currentPage)`），提示 `message.success(intl('operation-successful'))`（推测文案「操作成功」），关闭弹窗并重置表单。
  5. 失败：`message.error(res.message || intl('network-error-tip'))`（推测文案为网络错误提示）。
- 取消：关闭弹窗并重置表单。

### 6.2 导入弹窗

- c7n `Modal`，标题 **导入**（key `hzero.common.button.save.import`），`width: 600`，`closable: false`，`footer: null`。
- 内容（左侧标签区 padding-left 100px，标签绝对定位：`left: 0.24rem; width: 100px; text-align: right; padding-right: 0.1rem`）：
  1. 「模板下载」行：标签 **模板下载**（key `download-template`）；右侧为可点击链接，颜色 `rgb(41, 190, 206)`（#29BECE），`cursor: pointer`，前面有 18px 宽的 Excel 图标（`margin-right: 8px`），文字 **设备管理员配置**（key `facility-management-staff`）。点击后通过 `GET {HZERO_FILE}/v1/{orgId}/files/download-by-key?fileKey={templateFile}` 下载 blob，保存为 xlsx，文件名为「设备管理员配置」（空格替换成 `_`）。下载失败时提示 `message.error(intl('network-error-tip'))`。
     - `templateFile` 的来源：页面加载时查值集 `CRM.USERLIST.TEMPLATE`（`GET /hpfm/v1/{orgId}/lovs/data?lovCode=CRM.USERLIST.TEMPLATE`），取 `meaning === '设备管理员配置模板'` 那一项的 `value`。
  2. 「上传文件」行：标签为红色 `*` + 空格 + **上传文件**（key `upload-file`）+「:」；控件为 `Upload.Dragger` 拖拽上传区（`multiple: false`，上传地址 `{HZERO_FILE}/v1/{orgId}/files/multipart`，额外参数 `tenantId`、`bucketName: 's3'`、`directory: '/customer/operationManual'`，请求头 `Authorization: bearer {token}`）。
     - 拖拽区内容（padding 20px 0）：40px 宽的上传图标；文字「**将文件拖到此处，或**」（key `drag-the-file-here`）+ 颜色 `#29BECE` 的「**点击上传**」（key `click-upload`）；提示「**只能上传xls、xlsx格式文件**，**文件不能超过50M**」（keys `upload-format-tip`、`upload-max-tip`，两句之间用中文逗号连接）。
     - `beforeUpload` 校验：扩展名必须是 `xls` 或 `xlsx`，否则提示 `message.error('只能上传xls、xlsx格式文件')` 并拒绝；文件大小必须 `< 51MB`（代码写的是 `size/1024/1024 < 51`，文案说 50M），否则提示 `message.error('文件不能超过50M')`。校验通过后把文件放进 `files`（只保留 1 个），并返回 false，**阻止自动上传**。
     - onRemove：从 `files` 中按 name 移除。
- 底部按钮：**取消**（`cancel`）、**确定**（`confirm`，保存期间显示 loading）。
- 确定（`bindConfirm`）：防重复提交；表单校验；`files` 为空时提示 `message.error('请上传导入文件')`（key `please-upload-file`）；否则用 FormData 包装 `file`，`POST /customer/v1/{orgId}/customer-device-managers/import`。成功时刷新当前页，提示 `message.success('导入成功')`（key `import-succeeded`），关闭弹窗并清空文件；失败时提示 `network-error-tip`。
- 取消：关闭弹窗，清空 files。

### 6.3 删除确认

- `Modal.confirm({ title: intl('confirm-delete-tip', '确定删除此项吗？') })`，标题文案为 **确定删除此项吗？**
- onOk：`POST /customer/v1/{orgId}/customer-device-managers/delete?id={id}`，body 为 `{id}`。成功时提示 `message.success(intl('hzero.common.notification.success.delete'))`（推测为「删除成功」）并刷新当前页；失败时提示 `res.message || network-error-tip`。

### 6.4 导出

- HZERO `ExcelExport` 组件（`hzero-permission-btn`）。`defaultSelectAll: true`（导出列默认全选），文件名为 `设备管理员配置_{YYYYMMDD}`（名称中的空格替换为 `_`），请求地址 `/customer/v1/{orgId}/customer-device-managers/export`，查询参数用 `getQueryParameter()`。
- 按钮样式：`color:#333333; background:#ffffff; margin-left:0.1rem; margin-right:0.1rem; vertical-align:middle`。
- `getQueryParameter()`：取查询 DataSet 的第一条数据；若有 `time` 则拆成 `startDate`（`YYYY-MM-DD 00:00:00`）和 `endDate`（`YYYY-MM-DD 23:59:59`）；`countryCode` 取 `.citycode`；去掉值为 undefined、null 或 `''` 的键。本页查询字段中没有 time 和 countryCode，这部分是通用代码，实际不生效。

## 7. 交互逻辑

- DataSet：`pageSize: 20`，`autoQuery: true`（进入页面自动查询），`primaryKey: 'id'`，`dataKey: 'data.content'`，`totalKey: 'data.totalElements'`，`selection: false`（**没有勾选列**）。
- 列表接口：`GET /customer/v1/{orgId}/customer-device-managers/list`，查询参数为 crmCustomerName、crmCustomerNo、adminMysanyNo。
- DataSet 还配置了 update transport：`POST /customer/v1/{orgId}/customer-device-managers`，`data[0]`（页面实际通过弹窗直接调用接口）。
- 查询字段 `adminMysanyNo` 设置了 `labelWidth: '130'`（所以第 3 个标签列宽 1.3rem）。
- **管理员手机号列的渲染**：`(internationalTelCode ? '(' + internationalTelCode + ')' : '') + adminPhone`。也就是说，`(62)81222225008` 是由区号字段 `internationalTelCode = "62"` 和 `adminPhone = "81222225008"` 拼出来的。第 1 行没有区号也没有号码，所以单元格为空。示例数据还原为原始字段时，可以拆成 `internationalTelCode` + `adminPhone`（见下方补充）。
- 操作列：`header` 为 `intl('hzero.common.btn.action')`，显示「操作」；`width: 130`；`lock: 'right'`；command 返回「编辑」（默认 c7n 按钮）和「删除」（`color: 'red'`）。所有行都显示，没有条件。
- 每次增、删、改或导入成功后，都刷新**当前页**（不回到第 1 页）。

## 9. 其他细节

- 导出按钮用的是 antd v3 的 `ant-btn`，不是 c7n 按钮，所以外观略有差异；重写时统一用 AntD 5 `Button` 即可。
- 尺寸单位是 rem，HZERO 中 1rem = 100px（0.36rem = 36px 行高，1rem = 100px 列宽）。
- 管理员MySany账号的值格式不一，有邮箱、手机号、自定义账号（如 `PT.Chimarder777`），不要加格式校验。
- 管理员手机号带国家区号括号前缀，如 `(62)`（印尼）。
