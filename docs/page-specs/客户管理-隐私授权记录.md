# 客户管理-隐私授权记录 页面规格

源文件：`客户管理-隐私授权记录.html`。外壳为 HZERO/c7n 快照，主内容区是**手工拼装的 c7n 结构**（HTML 注释：“查询表单：4 列栅格，与账户管理一致”、“查询/重置”、“表格：账户管理同款外层结构”）。页面级脚本两段：`local-field-interact`（下拉 + 日期区间浮层）与 `local-mock-query`（离线模拟查询/分页），逻辑已完整提取于第 7 节。`local-nav-interact`、`local-layout-fix` 已忽略（其中 layout-fix 有两条与本页相关：表格 `min-width:100%` 撑满、浮层外壳样式，见第 8 节）。

尺寸换算：1rem = 100px。

## 1. 页面标题、面包屑、页签

- 页面标题：**隐私授权记录**
- 标题栏右侧（`page-head-operator`）：`导出` 按钮（见第 3 节）。
- 面包屑：无；页内 tabs：无。
- 顶部多页签栏（框架层）：工作台、月活跃用户、用户留存率、**隐私授权记录**（激活，占据原“账户管理”位置）、异常申诉、租户审核、设备管理员配置、组织管理、直接创建租户、客户认证使用、客户分析。
- 左侧一级菜单高亮：客户管理。
- 全局水印“产品顾问-刘伏旺”（同其他页面）。

## 3. 工具栏按钮

- `导出`：位于页面标题栏右侧。自定义内联样式：文字色 `#FFFFFF`（rgb 255,255,255），背景色 **`#29BECE`**（rgb 41,190,206，青色），`padding:0 15px`，`font-size:12px`，`border-radius:2px`，`height:28px`，`line-height:1`。左侧图标 `anticon-export`（`margin-right:8px; font-size:12px`）。快照中无点击逻辑（应导出当前筛选条件的记录）。
- 表格上方 `c7n-pro-table-toolbar` 初始为空，查询后用作“结果条数提示条”（见第 7、8 节）。

## 4. 表格

c7n Pro Table，带边框，可拖拽列宽，无勾选列、无操作列。表格固化宽度 7.6rem，`local-layout-fix` 加了 `.c7n-pro-table-content > table { min-width:100% }` 使其撑满，末列“同意时间”吸收余量。

| 顺序 | 标题 | 字段 | 宽度 | 最小宽度 | 对齐 | 固定 | 渲染 |
|---|---|---|---|---|---|---|---|
| 1 | 客户ID | `customerId` | 120px | 50px | 左 | 否 | 纯文本（8 位数字字符串） |
| 2 | 客户昵称 | `alias` | 120px | 50px | 左 | 否 | 纯文本 |
| 3 | 手机号 | `phone` | 140px | 50px | 左 | 否 | 纯文本，格式 `+区号 号码`（如 `+86 13982033231`） |
| 4 | APP/PC | `terminal` | 100px | 50px | 左 | 否 | 纯文本 `APP` / `PC` |
| 5 | 同意类型 | `consentType` | 130px | 50px | 左 | 否 | 纯文本 |
| 6 | 版本号 | `version` | 100px | 50px | 左 | 否 | 纯文本（如 `V2.1`） |
| 7 | 同意时间 | `consentTime` | 自适应（吸收余量） | 50px | 左 | 否 | `YYYY-MM-DD HH:mm:ss` |

- 数据行单元格：单行固定高度 `height:0.36rem; line-height:0.34rem`（36px），超长截断，HTML 转义输出。
- 排序：按同意时间**倒序**。

## 6. 弹窗、抽屉、详情页

无。`c7n-pro-modal-container` 为空。无详情/编辑视图。

### 浮层（由 `local-field-interact` 实现，重写时用 antd Select / RangePicker 即可）
- **下拉浮层**：最小宽度 = 触发控件宽度；选项列表逐项为 `data-options` 的值；当前值项加 selected 样式；点击选项即设值并关闭。点击控件右侧清除图标 → 值清空（显示文本也清空）并关闭。再次点击同一控件 → 关闭。打开下拉会先关闭日期浮层，反之亦然。点击页面任意其他地方关闭所有浮层。浮层位置：控件下方 2px；若下方空间不足且上方够，则显示在上方（间隔 4px）；水平方向限制在视口内（左右留 4px）。
- **日期区间浮层**：双月面板（左面板有 `«` 上一年、`‹` 上一月；右面板有 `»` 下一年、`›` 下一月；右面板 = 左面板 + 1 个月），面板标题 `YYYY年 M月`，星期表头 `日 一 二 三 四 五 六`（周日起始），6 行 × 7 列，非本月日期灰显（old/new），今天高亮（today），起止日期 selected，中间日期 in-range。底部脚注只有一个链接 `清除`（左对齐，`padding:0 .12rem`）。
  - 选择规则：第一次点击设起点（清空终点）、浮层保持打开；第二次点击设终点，若早于起点则自动交换；选完即关闭。每次点击都实时回填输入框（`YYYY-MM-DD`）。
  - 打开时从输入框已有值解析起止；面板初始月份 = 起点所在月，没有起点则为当前月。
  - `清除` 或输入框清除图标 → 起止均清空并关闭。

## 7. 交互逻辑（`local-mock-query` 完整规则）

### 7.1 状态
`state = { rows: null, page: 1, size: 20, desc: '' }`。`rows === null` 表示“未查询”（初始态/重置后）。

### 7.2 读取筛选条件
- 文本字段 `customerId`、`alias`、`phone`、`version`：取值并 `trim()`。
- 下拉 `terminal`、`consentType`：值为空或 `全部` 都视为不限。
- 时间区间：开始/结束日期字符串（`YYYY-MM-DD`），可只填一端。

### 7.3 过滤规则（match）
- 客户ID：**包含**匹配（区分大小写，原样子串）。
- 客户昵称、手机号、版本号：去掉所有空白并转小写后做**包含**匹配。
- APP/PC、同意类型：**精确等于**。
- 时间区间：取同意时间的日期部分（前 10 位），`>= 开始日期` 且 `<= 结束日期`（含两端，按日比较）。

### 7.4 查询（点击“查询”或在查询区内按 Enter）
1. 从数据池过滤。
2. 若结果为空 **且** 填写了“身份类”条件之一（客户ID / 客户昵称 / 手机号 / 版本号），则**按条件现场合成** 3~12 条记录（种子 = 所有条件用 `|` 拼接后的 FNV 哈希，同条件结果固定）：客户ID/昵称/手机号用输入值（未填则随机），终端用所选值或随机（82% APP），同意类型用所选值或随机（PC 只会是 `隐私协议`/`用户服务协议`），版本号用输入值或随机，时间在所选区间内随机（未选则过去 730 天内；结束日期包含当天 23:59:59）。（此为演示用兜底，真实系统应直接返回后端结果。）
3. 页码重置为 1；生成条件描述；重新渲染提示条、表格、分页。

### 7.5 条件描述文案（desc）
按顺序拼接，用 `；` 分隔，外包 `（条件：...）`：
- `客户ID 含「xxx」`
- `昵称 含「xxx」`
- `手机号 含「xxx」`
- `终端 = APP|PC`
- `同意类型 = xxx`
- `版本号 含「xxx」`
- `同意时间 {开始或“不限”} ~ {结束或“不限”}`（只要有任一端）
- 若无任何条件：`（未设置筛选条件，返回全部记录）`

### 7.6 结果提示条（表格工具栏位置）
- 未查询时：为空（不显示）。
- 查询后：`共查询到 <b>N</b> 条授权记录` + 条件描述。
  - 外层：`padding:6px 4px 10px; font-size:12px; color:#5a6b87; line-height:18px`
  - 数字 N：加粗，`color:#1c3f94; font-size:13px`
  - 条件描述：`color:#8a99b3; margin-left:6px`

### 7.7 表格空状态
- 未查询（rows=null）：`请添加筛选条件后查询数据`
- 查询结果为 0：`暂无符合条件的数据`

### 7.8 重置（点击“重置”）
- 清空所有文本框；两个下拉恢复显示 `全部`（值清空）；日期区间清空。
- `rows = null`、page=1、desc 清空 → 提示条消失，表格回到 `请添加筛选条件后查询数据`，分页 `1 - 0 / 0` 全禁用。
- 重置**不会**触发查询。

### 7.9 分页
- 信息文本：`{from} - {to} / {total}`，其中 from = total>0 ? (page-1)*size+1 : 1；to = min(page*size, total)。（因此空时显示 `1 - 0 / 0`。）
- maxPage = max(1, ceil(total/size))；page<=1 时首页、上一页禁用；page>=maxPage 时下一页、末页禁用。
- 首页 → 1；上一页 → page-1；下一页 → page+1；末页 → ceil(total/size)；越界自动夹紧。未查询时点击无效。
- 修改“每页行数”（10/20/50/100）→ size 更新，page 重置为 1，重新渲染表格和分页（提示条不变）。

### 7.10 导出
快照无逻辑。建议：按当前查询条件导出；未查询时可提示先查询（推断，原型无依据）。
