# 直接注销租户

路由：`#/customer/tenant-cancel`。客户管理下，位于直接创建租户之后。

## 已实现原型

租户信息包含姓名、手机号码（脱敏）、邮箱、用户名；筛选、列表、详情及注销弹窗同步展示或支持查询。新增注销记录保留上述信息快照。

- 按租户号码、名称、操作人、注销时间筛选；记录列表及详情。
- 注销租户按钮打开表单，选择租户号码及名称，展示已绑定客户联系人和脱敏手机。
- 必须发送并验证客户验证码才可提交；切换租户清除验证状态。验证码绑定租户、5分钟过期、60秒重发间隔、最多5次尝试，提交时重新校验并一次性消费。禁止重复注销。
- 授权人职务及权限依据、客户书面指令或工单编号、注销原因、数据处置安排、客户告知确认必填。部分保留时须填数据范围、法律依据、访问限制及截止或复核日期。
- 记录操作人、操作时间、验证时间及结果；不保存验证码正文。
- 全部为本地内存模拟，刷新重置；演示码123456，不发送短信，不删除真实租户或数据。示例租户为虚构数据。

## 欧盟规则与产品推断

依据：https://eur-lex.europa.eu/eli/reg/2016/679/oj/eng/

GDPR主要保护自然人的个人数据，企业租户关闭不等于所有个人数据均必须删除。第5条要求最小化及存储期限限制；第12条涉及身份核验和权利请求期限；第17条规定删除权及法律义务、法律请求等例外；第19条涉及接收方通知；第28条涉及处理者按控制者指令处理，以及服务结束时按控制者选择返还或删除（依法保留例外）。验证码是本产品验证方式，并非法定统一要求，也不能单独证明企业代表权限。

表单字段是落实上述责任的产品建议，不是欧盟统一强制字段清单。不得默认收集身份证复印件。书面指令应关联受控工单或授权材料，验证码只作为联系渠道验证。

## 上线前待确认（本次补全与推断）

- 本次按上下文理解为“服务商代办注销”；若用户所说“代为注册”确指开户，需另补创建租户流程：控制者/处理者角色、适用处理依据、隐私告知版本/时间/渠道、授权凭证、处理协议编号；不能把所有处理依据都写成同意。
- 联系人须来自已核实的租户授权资料，不能临时输入替代；真实数据源、短信服务和权限控制未接入。
- 正式服务端须绑定操作者/租户/操作意图的短期验证凭证、限流、并发防重及审计；当前固定验证码仅用于演示。
- 租户关闭、个人账号、成员权限、设备关系、数据导出、删除/匿名化、备份到期、处理者及接收方通知应分别跟踪；本原型的“已注销（模拟）”不表示真实数据删除完成。
- 真实上线应记录执行任务、删除/返还结果、完成时间、通知回执和失败重试；依法保留的类别与期限由适用成员国法律及合同核定，审计记录也须设置最小化与保留期限。
- GDPR权利请求通常应在一个月内答复，符合条件时可延长两个月并在首月通知理由；不能将租户关闭机械套用为所有自然人权利请求。
