# 客户分析-用户留存率 页面规格

> 来源：`客户分析-用户留存率.html`（HZERO 线上系统 c7n-ui 渲染后的 DOM 快照；无页面级交互脚本，`local-nav-interact` 和 `local-layout-fix` 已忽略）。
> 补充来源：同目录线上打包源码 `assets/packages/gcp-front-admin/static/js/73.d70fafdb.chunk.js`（module 1415，即本页组件和 DataSet），样式来自 `assets/packages/gcp-front-admin/static/css/73.873f508c.chunk.css`。
> 复杂度：**低**。只读报表列表，结构与「月活跃用户」几乎一样。快照保存时表格**正在加载且没有数据**（有 loading 遮罩、显示“暂无数据”、留存率为 `--%`）。

## 1. 页面标题、面包屑、页签

- 页面标题：**用户留存率**（`PageHeaderWrapper title`）；`.page-head-operator` 为空。
- 面包屑：无。菜单路径为一级菜单「**客户分析**」（侧栏激活项 `hzero-main-menu-item-hzero-customer_analysis`）下的「用户留存率」。
- HZERO 多页签：工作台（home 图标，不可关闭）/ 月活跃用户 / **用户留存率（激活）** / 账户管理 / 异常申诉 / 租户审核 / 设备管理员配置 / 组织管理 / 直接创建租户 / 客户认证使用 / 客户分析。
- 页面内部没有 Tabs。
- 顶栏和侧栏与其他 HZERO 页面相同（MySANY管理平台、新加坡站点、三一集团、简体中文、产品顾问-刘伏旺；侧栏菜单顺序同月活跃用户页）。

| # | 标签 | name | 控件 | placeholder | 选项 | 默认值 | 其他 |

| 2 | 查询国家 | `countryCodes` | LOV 多选（`lovCode: CUSTOMER.COUNTRY`，`type: object`，`multiple: true`，右侧搜索图标，可清除） | 请选择国家 | LOV `CUSTOMER.COUNTRY`：`textField: cityname`，`valueField: citycode` | 空 | 提交时转成 `citycode` 逗号拼接的字符串 |

## 3. 工具栏

整行是提示条（`.local-table-tips-bar`：`flex; align-items:center; justify-content:space-between; width:100%`；工具栏上下 padding 各 0.16rem）。

- **左侧指标**（`.customer_headerTips__2rYFL`：`display:flex; align-items:center; gap:30px; font-size:14px; width:70%`，子 div 颜色 `#333`）：
  - 第 1 行（24px，行高 1.5）：**`用户留存率 = {retentionRate}%`**。快照中为「**用户留存率 = --%**」（初始值 `--`，接口未返回或返回空值时也显示 `--`）。
  - 第 2 行（14px，与第 1 行间距 0.04rem）：**用户留存率=本月新注册的用户下月活跃用户数/本月新注册用户数**
- **右侧**：「**导出**」按钮（HZERO ExcelExport 权限按钮，图标 `anticon-export`；文字按钮样式：`color:#29bece; padding:0 0.12rem; border:none; margin:0; background:transparent`）。

## 7. 交互逻辑

- **列表接口**：`GET /customer/v1/{orgId}/infos/new-register-user`。transport.read 的处理：`yearMonth` 格式化为 `YYYY-MM`；`countryCodes` 转为 citycode 的逗号拼接；处理后的参数同时传给留存率接口；最终请求数据为 `{...params, ...处理后参数}`。
- **留存率接口**：`GET /customer/v1/{orgId}/infos/new-register-user/retention-rate?{同上参数}`，返回的 `data` 写入 `retentionRate`，显示为「用户留存率 = {data}%」。每次列表请求都会触发（翻页也会触发）；重写时可以改成只在查询条件变化时请求。
- **导出（工具栏按钮）**：ExcelExport，`method: get`，`defaultSelectAll: true`，文件名 `用户留存率_{YYYYMMDD}`，`requestUrl: /customer/v1/{orgId}/infos/new-register-user`，`queryParams = getQueryParameter()`（yearMonth 格式化、countryCodes 拼接，并去掉 undefined、null、'' 的键）。
  - 源码中另有一个未被调用的 `exportExcel()`：`GET /customer/v1/{orgId}/infos/new-register-user/export`（blob），文件名为 `用户留存率_{YYYYMMDD}`。如果后端提供的是这个直连导出接口，也可以用它。
- 重置：清空国家和印尼标签两个查询条件，查询月份恢复为默认的当前月，然后重新查询。
- **加载状态**：快照保存时处于请求中，`.c7n-spin.c7n-spin-spinning` 显示 4 个点的旋转加载图标，表格容器加了 `c7n-spin-blur`（模糊/半透明遮罩）。重写时对应 AntD Table 的 `loading`。

## 8. 特殊视觉

- 指标大字「用户留存率 = --%」（24px，`#333`），下方是公式说明（14px）。指标区宽 70%，导出按钮靠右。
- 导出为青色文字按钮 `#29bece`。
- 没有图表，也没有统计卡片。
- 空状态文案「暂无数据」，并且会随横向滚动保持可见（sticky）。
- 有 loading 遮罩（见上）。
- 水印：14 个 `div.mask_mark`，文字「产品顾问-刘伏旺」，样式 `rotate(-15deg)`、`opacity 0.2`、12px、微软雅黑、颜色 `rgb(170,170,170)`、尺寸 210×60、`pointer-events:none`、`z-index 1000`。分两列，left 为 20px 和 391px；top 依次为 56、174、292、410、528、646、764。

## 9. 其他细节

- 与「月活跃用户」页共用同一套查询字段、表格列、是/否值集（本地定义 `{是:'1', 否:'0'}`）和导出样式，只有接口、指标名、公式和导出文件名不同。重写时建议抽成通用的 `UserMetricReportPage` 组件，用配置区分：

| 配置项 | 月活跃用户 | 用户留存率 |
|---|---|---|
| title | 月活跃用户 | 用户留存率 |
| listUrl | /customer/v1/{orgId}/infos/active-user | /customer/v1/{orgId}/infos/new-register-user |
| rateUrl | …/active-user/active-rate | …/new-register-user/retention-rate |
| 指标文案 | 活跃率 = {v}% | 用户留存率 = {v}% |
| 公式 | 月活跃率=本月活跃用户数/本月用户总数 | 用户留存率=本月新注册的用户下月活跃用户数/本月新注册用户数 |
| 导出文件名 | 月活跃用户_{YYYYMMDD} | 用户留存率_{YYYYMMDD} |

- 方案文档 §9 指出：注销用户应计入留存率分母并视为流失，并建议增加「剔除注销用户」的对比开关（可作为后续增强，原型中没有）。
- 尺寸单位为 rem（1rem = 100px）。
