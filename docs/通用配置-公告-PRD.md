# 通用配置 · 公告（系统通知）产品需求文档（PRD）

> &nbsp;

---

## 一、背景与目标

### 1.1 背景

平台近期将执行安全策略调整：**后管平台仅允许在三一内网环境下登录与访问，公网入口关闭**。该变更影响全体后管用户（运营、客服、系统管理员、合规/法务等）。

&nbsp;

### 1.2 目标

1. 建立后管平台的系统公告发布与管理能力，菜单位置 `通用配置 → 公告`。
2. 支持以「登录后弹窗系统通知」方式触达全量后管用户，替代仅靠口头/群通知的不可追溯方式。
3. 支持「强制阅读」：用户须勾选确认方可关闭弹窗，确认行为落库留痕，满足安全变更类通知的举证要求。
4. 沉淀阅读数据（触达人数、已读率、确认人数），支撑发布人评估触达效果、决定是否补充通知渠道。
5. 完成本次「内网访问调整」公告的文案定稿与发布（文案见附录 A）。

## 二、术语与概念


| 概念      | 说明                                             |
| ------- | ---------------------------------------------- |
| 公告      | 后管平台级通知，由后管发布、面向后管用户，区别于 C 端消息                 |
| 触达方式    | 公告触达用户的渠道，**多选**（至少一项）：系统通知（登录弹窗）/ 站内消息 / 三一飞书 |
| 强制阅读    | 用户须勾选「我已知晓」类确认项后才能关闭弹窗；用于安全变更等必须确认知晓的场景        |
| 确认后不再弹出 | 同一账号完成阅读确认后，后续登录不再弹出该公告（默认开启）                  |
| 生效/失效时间 | 公告的生命周期窗口；失效后弹窗自动停止，列表状态置为「已失效」                |
| 阅读率     | 弹窗触达人数 / 应触达人数（登录过且在生效窗口内的账号数）                 |

## 三、用户与场景


| 角色                | 场景                            | 使用功能                   |
| ----------------- | ----------------------------- | ---------------------- |
| 运营主管 / 系统管理员（发布人） | 平台级变更（安全策略、维护窗口、规则调整）需全量通知并留痕 | 新建/编辑/发布/取消发布公告，查看阅读数据 |
| 普通后管用户（接收人）       | 登录平台后被系统通知弹窗触达，知晓平台变更         | 阅读弹窗、勾选确认              |
| 合规/法务             | 安全变更通知的触达举证                   | 查看公告列表、阅读与确认数据         |


核心用户故事：

1. 作为运营主管，我要发布一条"平台切换内网访问"的系统通知，让所有后管用户在下次登录时必然看到，并知道有多少人已确认，以便在生效日前完成触达、留存举证材料。
2. 作为后管用户，我希望弹窗把"什么时候变、影响什么、我该怎么做"一次说清楚，且不要在我确认之后反复打扰我。

## 四、需求范围总览

```
通用配置 → 公告
├── 公告列表（查询 / 分页）
├── 新建 / 编辑公告（页内编辑视图，含触达方式与阅读设置）
├── 发布（立即生效 / 定时生效）/ 取消发布 / 删除草稿 / 基于此公告新建
├── 公告详情（只读视图 + 触达与阅读数据）
└── 用户侧：登录后弹窗系统通知（强制阅读 / 确认留痕 / 不再弹出）
```

公告状态机（与「隐私/服务协议管理」一致）：

```
                 提交发布(定时生效)
 草稿 DRAFT ─────────────────► 待生效 SCHEDULED ──到点──► 已发布 PUBLISHED ──到期──► 已失效 EXPIRED
    ▲  │ 编辑/删除                  │                        │                        │
    │  └──提交发布(立即生效)─────────────────────────────────┘                        │
    └──────────── 取消发布（退回草稿）◄┘                查看 + 基于此公告新建 ◄──────────┘
```

## 五、功能需求

### 5.1 公告列表

**筛选区**：公告标题（模糊）、公告类型（系统通知/维护公告/运营公告）、公告状态（草稿/待生效/已发布/已失效）、发布时间范围。

**列表列**：


| 列           | 说明                                           |
| ----------- | -------------------------------------------- |
| 公告编号        | `GG-yyyyMMdd-序号`，可点击进详情                      |
| 公告标题        | 超长省略，悬浮完整展示                                  |
| 公告类型        | 标签：系统通知（蓝）/ 维护公告（橙）/ 运营公告（紫）                 |
| 触达方式        | 标签（多选回显）：系统通知 / 站内消息 / 三一飞书                  |
| 生效时间 / 失效时间 | 空失效时间显示「长期有效」                                |
| 状态          | 状态点样式（与协议管理一致）：草稿（灰）/ 待生效（青）/ 已发布（绿）/ 已失效（灰） |
| 发布人 / 阅读率   | 阅读率 = 已读/应触达，草稿与待生效显示「—」                     |


**操作列**（按状态动态）：


| 状态  | 可用操作       |
| --- | ---------- |
| 草稿  | 编辑、发布、删除   |
| 待生效 | 查看、取消发布    |
| 已发布 | 查看、基于此公告新建 |
| 已失效 | 查看、基于此公告新建 |


**默认排序**：状态（待生效 > 已发布 > 草稿 > 已失效）→ 生效时间倒序。

### 5.2 新建 / 编辑公告（页内编辑视图）

新建/编辑不再是弹窗，采用与「隐私/服务协议管理 → 新建版本」完全一致的页内编辑视图：顶部「← 返回列表 + 标题（含公告编号）+ 状态标签 + 保存草稿/提交发布按钮」，下方依次为「基础信息」「公告正文」两张卡片；「查看」进入同一视图的只读态（控件禁用、正文不可编辑），并追加展示「触达与阅读数据」卡片。

**基础信息卡片字段**：


| 字段      | 必填  | 类型        | 规则                               |
| ------- | --- | --------- | -------------------------------- |
| 公告标题    | 是   | 文本 ≤60 字  | 必填校验；空值提交拦截并提示                   |
| 公告类型    | 是   | 枚举        | 系统通知 / 维护公告 / 运营公告               |
| 触达方式    | 是   | **多选框**   | 系统通知 / 站内消息 / 三一飞书；至少勾选一项        |
| 生效方式    | 是   | 单选 + 日期时间 | 立即生效 / 定时生效（默认定时生效）；立即生效时禁用定时时间  |
| 失效时间    | 否   | 日期时间      | 可空 = 长期有效                        |
| 强制阅读    | 否   | 开关        | 仅触达方式含「系统通知」时可配置；开启后须勾选确认项才能关闭弹窗 |
| 确认后不再弹出 | 否   | 开关        | 默认开启；关闭 = 每次登录都弹出（慎用，见 §9-E5）    |


**公告正文卡片**：语言子 Tab（简体中文 / English / Bahasa Indonesia / 繁體中文，与协议管理一致）+ 富文本工具栏（加粗/斜体/下划线/标题/列表/链接/表格）+ 字数统计；发布前至少填写简体中文版正文。

**发布动作**：「提交发布」后按生效方式流转——立即生效 → 已发布并即时触达；定时生效 → 待生效，到点自动触达。记录发布人、发布时间，写操作日志。「保存草稿」仅落草稿，不入触达链路。

### 5.3 取消发布 / 删除 / 基于此公告新建

- **取消发布**：仅「待生效」状态可取消；须填写取消原因（≥5 字）；取消后公告退回「草稿」状态，可重新编辑发布；操作入日志。
- **删除**：仅「草稿」状态可删除，删除前二次确认；已发布 / 已失效的公告永久留存供举证，不提供删除（与协议管理一致）。
- **基于此公告新建**：仅「已发布 / 已失效」状态提供；复制原公告全部内容生成新草稿（新编号），历史阅读数据不随复制。
- **并发保护**：同一时间最多一条「强制阅读 + 系统通知」公告处于已发布状态（见 §9-E3 排队策略）。

### 5.4 弹窗系统通知（用户侧交互）

**触发时机**：用户登录成功进入工作台后弹出（页面渲染完成后延迟弹出，避免遮挡加载态）。

**弹窗结构**（对应原型 `#noticeMask`）：

```
┌──────────────────────────────────────────┐
│ 🔔 系统通知            2026-10-09 10:00 ✕ │
├──────────────────────────────────────────┤
│        关于 MySANY 管理平台切换内网访问的公告  │
│  正文（见附录 A）：                         │
│  一、切换时间与影响范围                      │
│  二、办公场所外的访问方式（VPN）              │
│  三、功能与数据不受影响                      │
│  四、异常反馈路径                           │
│                              MySANY 管理平台 │
├──────────────────────────────────────────┤
│ ☑ 我已知晓：11 月 1 日起需通过三一内网（或 VPN）│
│           访问本平台                        │
│           [ 我已知晓 ]                      │
└──────────────────────────────────────────┘
```

**交互规则**：


| #   | 规则                                                                               |
| --- | -------------------------------------------------------------------------------- |
| R1  | 未勾选确认项时，「我已知晓」按钮置灰不可点                                                            |
| R2  | 强制阅读开启时，点右上角 ✕ 关闭被拦截并轻提示「请先勾选我已知晓」；强制阅读关闭时 ✕ 可直接关闭（记为已读未确认）                      |
| R3  | 勾选并点击「我已知晓」→ 写入阅读确认记录（账号、公告、时间、IP），后续登录不再弹出该公告                                   |
| R4  | 多条公告同时命中生效窗口：按「强制阅读优先、生效时间近者优先」排序，**逐条弹出**（关闭一条后弹下一条，最多连弹 3 条，超出折叠为站内消息，见 §9-E3） |
| R5  | 弹窗展示公告语言跟随账号语言设置；无对应语言译文时回退默认语言并提示                                               |
| R6  | 会话内同一公告只弹一次；跨会话依据阅读记录判断                                                          |


### 5.5 阅读数据与统计


| 指标           | 口径                         |
| ------------ | -------------------------- |
| 应触达人数        | 生效窗口内登录过的后管账号数             |
| 弹窗触达人数 / 触达率 | 弹出过该公告的账号数 / 应触达人数         |
| 已读率          | 确认 + 直接关闭（非强制）人数 / 触达人数    |
| 确认人数         | 勾选「我已知晓」的人数（强制阅读公告的核心举证指标） |


详情只读视图内展示触达与阅读数据；列表页「阅读率」列取已读率。催办能力本期不做站内催办，未确认账号清单的导出为 P1 项（见 §11）。

发布、取消发布、删除操作写操作日志（操作人、时间、IP、动作、备注），日志不可编辑删除，保留 ≥3 年。

## 八、边界与异常场景


| #   | 场景               | 处理                                                 |
| --- | ---------------- | -------------------------------------------------- |
| E1  | 生效时间未到           | 不弹出；到点自动开始触达（定时任务扫描）                               |
| E2  | 失效时间到达           | 已弹出的当场允许关闭；后续登录不再弹出                                |
| E3  | 多条弹窗公告并存         | 强制阅读优先 + 生效时间近者优先，逐条弹出，连弹上限 3 条，其余降级为站内消息并在铃铛处聚合提示 |
| E4  | 用户在弹窗页停留超过 10 分钟 | 记录 `readTime` 以弹出时刻为准，确认时间以点击时刻为准                  |
| E5  | 「确认后不再弹出」关闭的公告   | 每次登录弹出直至失效；发布时对该组合二次提示打扰风险                         |
| E6  | 取消发布时有用户弹窗正打开    | 允许正常关闭，确认行为仍然有效并落库                                 |
| E7  | 多语言缺译文           | 回退默认语言，弹窗顶部提示「当前语言暂缺译文」                            |
| E8  | 站点差异             | 本期公告为平台级（全部站点可见）；按站点发布见 §11 Q2                     |

## 十一、交付拆分建议


| 阶段  | 内容                                       | 依赖              |
| --- | ---------------------------------------- | --------------- |
| P0  | 公告主表/阅读记录表 + 值集配置 + 列表/页内编辑视图/发布/取消发布/删除 | 值集配置（开发管理-值集配置） |
| P0  | 登录后弹窗系统通知（强制阅读、确认留痕、不再弹出、多公告排队）          | 登录态与账号语言        |
| P0  | 三一飞书触达通道对接                               | 飞书开放接口、应用审批     |
| P1  | 阅读数据统计 + 未确认名单导出                         | P0 阅读记录         |
| P1  | 多语言译文管理与回退                               | 多语言框架           |


**P0 验收标准（本次内网切换公告）**：公告发布后，目标用户首次登录即见弹窗；勾选确认前无法关闭；确认记录可在后管查询；生效日前确认率可实时统计；三一飞书渠道同步送达。
